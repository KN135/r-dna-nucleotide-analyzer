# r-dna-nucleotide-analyzer
Beginner R bioinformatics project for analyzing DNA nucleotide composition and GC content.
📊 What the program does

It takes:

ATGCGATACGCTTACG

and analyzes:

🧬 DNA sequence
🔢 Sequence length
A → Adenine count
T → Thymine count
G → Guanine count
C → Cytosine count
📊 GC content
